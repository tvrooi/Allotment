<objective>
Move the global keyboard focus rule into the CSS base layer so each shared control's own focus
treatment takes effect, and give the few components that relied on the global outline a visible
ring of their own.

Purpose: 02-UI-SPEC.md makes this a prerequisite of the set (D-03: one focus ring). Unlayered, the
global rule beats every Tailwind utility, so today a focused field shows its ring and a second
outline. The move changes keyboard focus on every screen, so it is its own plan with its own
regression tests (the UI checker's four items).
Output: the layered rule, focus rings on ContextMenu items and the Rules fields, an updated
DESIGN.md line, and browser tests that pin the behaviour.
</objective>
