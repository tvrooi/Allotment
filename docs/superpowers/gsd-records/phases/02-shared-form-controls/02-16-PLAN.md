`Textarea.tsx` and its tests, a Textarea card and gallery assertions.

The naming forms the set's controls accept (02-UI-SPEC.md, and the props each later plan
declares): a visible `label` that is a string (Field, Select, DatePicker, MonthPicker, Combobox,
RadioGroup), an `aria-label` alone with no visible label (Select, Combobox, RadioGroup, Checkbox,
Switch), or a visible label that is a React node rather than a string (Checkbox and Switch
`children`). The subject of a default message or a Clear button comes from those, in this order:
`errorLabel`, then the label when it is a string, then `aria-label`. A control whose only name is
a non-string node has no string to use, so its props require `errorLabel` when it can show a
default message (that is plan 02-13's type rule for a required toggle).

`client/src/utils/dates.ts` (`formatDay`) and `client/src/utils/dateRange.ts` (`formatMonth`).
Unit tests run in Node with no DOM: `renderToStaticMarkup(createElement(...))`.
