The subject of every default message here (02-UI-SPEC.md "Copywriting Contract") comes from
plan 02-16's one rule, `fieldSubject`: `errorLabel`, else the label when it is plain text (with
its own casing), else the `aria-label`. Each control maps its props onto it: a toggle passes
`label: children` and `ariaLabel: props['aria-label']`; RadioGroup passes its `label` and
`aria-label`. No control writes its own `errorLabel ??` fallback. A toggle whose only name is a
non-string `children` node has no string to use, so its props require `errorLabel` whenever
`isRequired` is passed with such a label and no `aria-label`.
