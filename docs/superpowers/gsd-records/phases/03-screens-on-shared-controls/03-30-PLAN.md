- `bulkEdit` compares `expectedCount` with every matched row (skipped fields included), so the
  expected count is the number of selected rows. Reconciled rows take category, payee and notes
  edits; transfers skip category and payee, split parents skip category, household-linked rows
  skip all three (`ledgerBlock`). The 409 text is "The selection now has N transactions, not M.
  Check it and try again."
- `MenuItem` already has `hint` (a second line inside the item, so it is part of the item's
  accessible name) and `disabled`; a disabled item's button is disabled, so a disabled sub-menu
  parent cannot open.
- `useCanSave()` is in hooks/useConnection.ts. The paused wording is typed in SavingPausedHint.tsx
  and nowhere exported.
- e2e/tests/connection.spec.ts shows how a desktop test pauses saving: `stopDesktopServer()` from
  `./serverControl`, then `window.dispatchEvent(new Event('visibilitychange'))` so a refetch fails,
  then the `Connection` status reads "Can't reach Allotment"; `startDesktopServer()` in `finally`.
  Playwright runs one worker, so stopping the server affects no other test.
