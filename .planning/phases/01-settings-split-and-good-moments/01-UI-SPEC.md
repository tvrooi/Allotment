## Spacing Scale

Tailwind's 4 px base, as the project uses it (DESIGN.md "Layout"). New markup in this phase uses only these values:

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px (`gap-1`, `mt-1`) | Breadcrumb chevron gaps, subtitle offset under the title |
| sm | 8px (`gap-2`) | Bar-to-plant gap, header button gap, glyph-to-label gap in the hero |
| 12 | 12px (`gap-3`, `px-3`) | Title-to-pill gap in the Accounts header (existing) |
| md | 16px (`PAGE_GUTTER` on phones, `py-4`) | Header vertical padding, phone gutter |
| lg | 24px (`PAGE_GUTTER` from `md`, `py-6`) | Desktop gutter, content top/bottom padding on the new pages |
| xl | 32px | Not used new |
| 2xl | 40px (`space-y-10`) | CategoryManager section gap (existing, unchanged) |
| 28 | 28px (`pr-7`) | Goal label row right inset = 20 px plant + 8 px gap, so the % sits under the bar's end |

Exceptions:
- Touch targets: every new link or button is at least 44 px tall below 768 px (`max-md:min-h-11`; `Button`/`ButtonLink` already meet this on phones). Breadcrumb links get a 44 px hit area with `max-md:py-3 max-md:-my-3` so the row does not grow.
- Existing 6 px values (`h-1.5` bar, `mt-1.5`, `gap-1.5`) in untouched markup stay. New markup does not add 2 px-step spacing.
- Plant box: 20 × 20 px on goal rows, 16 × 16 px in the hero (icon sizes, not spacing).

|------|----------------------|-------|
| Dominant (60%) | `--color-surface` `#ffffff` / `#262320` | Page bodies of `/accounts/connections`, `/budget/categories`, Settings, goal rows |
| Secondary (30%) | `--color-page` `#f7f5ef` / `#1c1a17`, `--color-surface-alt` `#efece9` / `#302c28` | `PageHeader` band, goal bar track, sidebar |
| Accent (10%) | `--color-brand-600` `#bf3e00` / `#ff8a57` (controls); `--color-brand-500` Marigold `#f46b35` (graphics) | See reserved list |
| Positive | `--color-positive` Sprout `#1b7550` / `#6cc695`, `--color-positive-subtle` | Reached-goal bar, plant stems and leaves, Ready to assign hero while its figure holds |
| Destructive | `--color-negative` `#cb2b30` / `#ff8f8c` | Existing delete-group / delete-category / Disconnect Up confirmations only (moved unchanged) |

Accent reserved for:
1. `brand-600`: the primary "Add account" button fill, the active Settings tab underline and label, link text and hover, the 2 px global focus outline.
2. `brand-500` (Marigold, graphics only, never text): the in-progress goal bar (existing), the bud's tip and the flower's petals.
3. `brand-700`: the flower's centre dot.

Ready to assign colour rules (critique decision + GLOSSARY.md "zero amounts"):
- While the figure holds (no account issue, no missing rate), the hero keeps `bg-positive-subtle` and the "Ready to assign" heading keeps `text-positive`, at $0 too.
- A $0 figure renders in `text-text` (normal colour), never green, red or caution. This applies to every $0 case, including "Nothing to assign yet".
- A caveat label at $0 is `text-text` weight 500 (it is a job to do, not praise); the caution colour stays on the existing todo line's `AlertCircle` icon.
- Doubtful figure (account issues or missing exchange rates): unchanged caution treatment.

## Screens and interaction contract

### 1. Connected banks under Accounts (WAVF-01)

**Route:** `/accounts/connections`, a new lazy page (`pages/AccountConnections.tsx`) in `App.tsx`, declared before `/accounts/:id` (static segments rank first in React Router; the order keeps intent obvious). Sidebar "Accounts" stays active (NavLink prefix match).

**Page layout:**
- Wrapper `flex flex-col h-full bg-surface`.
- `PageHeader` with `breadcrumbs={[{ label: 'Accounts', to: '/accounts' }, { label: 'Connected banks' }]}`, `title="Connected banks"`, `subtitle` = the panel's existing intro sentence (copy table). No header actions.
- Content: `flex-1 overflow-y-auto py-6 ${PAGE_GUTTER}` with `useScrollMemory('accounts-connections')`, inner `max-w-2xl` (same measure as the Settings panel today).
- `ConnectedAccounts` moves as it is with one edit: its top block (`h2` "Connected banks" plus intro `p`, both in the demo and the real variant) is removed, because the page header now carries the title and intro. Nothing else in the panel changes: provider toggle, Up panel, Plaid / SimpleFIN / Enable Banking sections, loading spinner, demo note.

**Entry points:**
| Where | Control | Spec |
|-------|---------|------|
| Accounts header (any account count) | `ButtonLink variant="secondary" size="sm"` with `Link2` 14 px, label "Connected banks", `data-guide="accounts.connections"` | Left of "Add account"; "Add account" stays the rightmost, primary |
| Accounts empty state | Existing secondary "Connect a bank" | `to="/accounts/connections"` |
| Up sync pill (`BankSyncPill`) | Existing | `to="/accounts/connections"` |
| `GettingStarted`, `TransactionTable`, `BankBalanceHint`, `Resilience`, `Housekeeping:55` | Existing links | `to="/accounts/connections"` |

**Click count:** Accounts → "Connected banks" (1) → "Up" in the provider toggle (2). Two is fewer than today's three. From the Up pill on Accounts it is one click to the page.

**Accounts header at 390 px:** the header row becomes `flex flex-wrap items-center justify-between gap-x-4 gap-y-2`. Below 768 px the title and Up pill hold the first line, and the action group (`flex items-center gap-2`) wraps to the second line, left-aligned, both buttons 44 px tall. No sideways scroll. At 768 px and up, one row as today.

**Back navigation:** the "Accounts" breadcrumb link (44 px phone hit area) and browser Back; scroll on return comes from `useScrollMemory`.

### 3. Settings after the split (WAVF-03)

### 4. Goal plant: seed to flower (WAVF-04, D-01 to D-04)

**Component:** `components/ui/Plant.tsx`, `Plant({ stage, size = 20, ground = true, className, ...dataAttrs })`, with a pure `plantStage(pct, complete)` exported beside it for unit tests.

**Stage rule** (`pct` is the unrounded value from `progressOf`; `complete` is the existing rule at `Goals.tsx:92`):

| Stage | Condition | Meaning |
|-------|-----------|---------|
| `seed` | not `complete` and `pct < 33` | Planted, including 0% and a $0 target |
| `seedling` | not `complete` and `33 <= pct < 66` | The brand sprout |
| `bud` | not `complete` and `pct >= 66` | Includes 100% when `fundingComplete === false`, and a goal completed by hand short of its target |
| `flower` | `complete` | Only when the money reaches the target (D-02) |

Status (paused, retired, completed by hand) and overdue do not change the stage or its colours; their existing text says so.

**Placement on the goal row** (replaces `Goals.tsx` ~225-245; the bar stays as today's progress record):
```
<div className="mt-3 pl-12">                         // unchanged wrapper
  <div className="flex items-center gap-2">
    <div className="flex-1 h-1.5 rounded-full bg-surface-alt overflow-hidden">…existing fill…</div>
    <Plant stage={stage} className="shrink-0" data-testid="goal-plant" data-stage={stage} />
  </div>
  <div className="flex items-center justify-between mt-1.5 text-xs pr-7">…existing label and %…</div>
</div>
```
At 390 px the bar still has about 240 px of track; the plant never wraps or shrinks.

**Drawing** (viewBox `0 0 20 20`, rendered at `size` px; colours by Tailwind `fill-*` / `stroke-*` utilities from `@theme` tokens only). The seedling is the brand mark's own sprout path (`client/public/logo.svg`), so the plant and the logo share one leaf shape. Reference geometry; the executor may adjust by ≤ 1 unit after the visual check, keeping the four silhouettes distinct at 100% zoom:

- Ground (all stages when `ground`): `<path d="M3 18.25h14" class="stroke-border" stroke-width="1.5" stroke-linecap="round"/>`.
- Brand sprout (`SPROUT`): `<path d="M20 51V27C8 28 2 20 2 9c12-1 18 5 18 14C20 14 26 8 38 9c0 11-6 19-18 18" class="fill-positive"/>` plus `<path d="M20 26v25" class="stroke-positive" stroke-width="5" stroke-linecap="round" fill="none"/>`, placed with a `transform`.
- `seed`: `<ellipse cx="10" cy="15.75" rx="2.75" ry="2" transform="rotate(-20 10 15.75)" class="fill-text-tertiary"/>`.
- `seedling`: `SPROUT` at `translate(4.4 3.72) scale(0.28)` (base lands on y 18).
- `bud`: `SPROUT` at `translate(5.2 5.76) scale(0.24)`; stem `<path d="M10 12V7.5" class="stroke-positive" stroke-width="1.4" stroke-linecap="round"/>`; bud `<path d="M10 2.75c1.6 1.2 2.4 2.5 2.4 3.6a2.4 2.4 0 0 1-4.8 0c0-1.1.8-2.4 2.4-3.6z" class="fill-brand-500"/>`.
- `flower`: `SPROUT` at `translate(5.6 6.78) scale(0.22)`; stem `M10 12.5V6` as above; five petals `r="2"` `fill-brand-500` at (10, 2.8), (12.28, 4.46), (11.41, 7.14), (8.59, 7.14), (7.72, 4.46); centre `<circle cx="10" cy="5.2" r="1.5" class="fill-brand-700"/>`.

**Accessibility:** `<svg aria-hidden="true" focusable="false">`, with no `<title>` and no role. Status stays in text: "Goal reached" (`text-positive font-medium`, existing) or "… to go", plus the %. The picture is never the only signal (D-03).

**Safe mode (D-04):** the plant has no amount in it. On `/goals`, Safe mode already replaces the whole list with `SafeModeNotice`, so plant and bar are hidden together. If a later screen shows goal rows under Safe mode at the "balances" level, the plant follows the bar: shown when the bar is shown.

**Light and dark:** every fill and stroke is a token that flips (`positive` #1b7550 / #6cc695, `brand-500` #f46b35, `brand-700` #9f3300 / #ffa57e, `text-tertiary`, `border`). Check on `bg-surface` and on row hover `bg-hover` in both themes.

**Motion:** none. Stage changes swap instantly; no `transition` on the SVG. Keep `Plant` a stable element so Phase 2's lazy bloom (deferred, D-07) can sit over it without changing this contract.

**Out of scope:** the dashboard's goal figures (`SummaryStats`) and category pages get no plant this phase.
